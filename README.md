# 🚀 HTML & CSS Learning Journey

Welcome to my personal learning repository! This repo documents my step-by-step progress, practice exercises, and mini-projects as I master modern web development fundamentals.

## 📌 About This Repository
As a software developer expanding my skill set, I believe that strong fundamentals are the key to building great web applications. This repository serves as a structured log of my journey starting from basic HTML tags up to responsive, modern CSS designs.

## 🗂️ Structure
The repository is organized progressively:
- **01-html-fundamentals/**: Core HTML tags, semantic elements, forms, and tables.
- **02-css-basics/**: Selectors, typography, box model, and styling techniques.
- **03-flexbox-grid/**: Modern layout designs using Flexbox and CSS Grid.
- **04-mini-projects/**: Real-world practice landing pages and components.

## 🛠️ Technologies Used
- HTML5 (Semantic Markup)
- CSS3 (Flexbox, Grid, Responsive Design)
- Git & GitHub
